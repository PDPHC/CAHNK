# ระบบธุรการชั้นเรียน V4

## ปรับเพิ่มใน V4
- แบบบันทึกทั้ง 8 แบบเลือกพิมพ์เฉพาะเดือนได้
- แบบบันทึกทั้ง 8 แบบพิมพ์ทุกเดือนในช่วงเปิด-ปิดภาคเรียนได้
- แบบรับทุนกรองรายการตามวันที่ของเดือนที่พิมพ์
- แบบโฮมรูมกรองตามเดือน และพิมพ์แยกแต่ละสัปดาห์ที่มีข้อมูล
- แบบจิตอาสาแยกข้อมูลกิจกรรมเป็นรายเดือน
- แบบออมทรัพย์ ช่อง “รวมสะสม” เป็นยอดยกมาจากทุกเดือนก่อนหน้า + เดือนปัจจุบัน
- หน้าพิมพ์ออมทรัพย์แสดงยอดสะสมของแต่ละเดือนตามลำดับเช่นเดียวกัน

ข้อมูลเดิมจาก V3 ยังคงใช้ storage key เดิม เพื่อให้ข้อมูลที่เคยบันทึกไว้ไม่ถูกแยกฐานใหม่


## V4.1 bug fix
- แก้ปุ่มพิมพ์ทุกเดือนที่เคยออกเพียงเดือนเดียวเมื่อใช้ข้อมูล Settings จากรุ่นเก่า
- Print Engine merge ค่าเริ่มต้นกับ Settings เดิมแล้ว
- หากวันเปิด/ปิดเรียนหาย ระบบมี fallback ตามภาคเรียน แทนการพิมพ์เพียงเดือนปัจจุบัน
- แถบหน้าพิมพ์แสดงจำนวนเดือนและช่วงเดือนที่กำลังพิมพ์


## V4.2
- เปลี่ยนฟอนต์หลักเป็น TH Sarabun New / TH SarabunPSK (ใช้ฟอนต์ที่ติดตั้งในเครื่อง)
- เพิ่มช่องลงชื่อท้ายหน้าพิมพ์ทุกแบบ: ครูประจำชั้น / วิชาการระดับมัธยมศึกษา / รองผู้อำนวยการฝ่ายบริหารงานวิชาการ
- ช่องลงชื่อถูกเพิ่มในแบบมาเรียน ออมทรัพย์ สุขภาพ พฤติกรรม อ่านออก-เขียนได้ รับทุน จิตอาสา และโฮมรูม


## V4.3
- รองรับครูประจำชั้น 2 คนในหน้าตั้งค่าและหน้าพิมพ์ทุกแบบ
- ถ้ากรอกเฉพาะครูประจำชั้นคนที่ 1: หน้าพิมพ์แสดง 3 ช่องลงชื่อ
  (ครูประจำชั้น / วิชาการ / รองผู้อำนวยการ)
- ถ้ากรอกครูประจำชั้นคนที่ 2: หน้าพิมพ์แสดง 4 ช่องลงชื่อ
  (ครูประจำชั้นคนที่ 1 / ครูประจำชั้นคนที่ 2 / วิชาการ / รองผู้อำนวยการ)
- ช่องลงชื่อปรับขนาดอัตโนมัติและใช้ TH Sarabun New เช่นเดิม


## V4.4 — ขยายฟอนต์หน้าจอ
- ขยายฟอนต์ตารางหน้ากรอกข้อมูลจากประมาณ 12px เป็น 17px
- ช่องกรอกข้อมูลและ Select เป็น 18px
- หัวข้อ เมนู ปุ่ม และคำอธิบายขยายตามสัดส่วน
- Checkbox ขยายให้กดง่ายขึ้น
- ตารางรายเดือนยังคงขนาดกะทัดรัดกว่าเล็กน้อย เพื่อไม่ให้กว้างเกินไป
- ไม่เปลี่ยนขนาดฟอนต์หน้าพิมพ์ A4 เพื่อป้องกันตารางล้นหน้า
- ใช้ TH Sarabun New / TH SarabunPSK / Sarabun เช่นเดิม


## V4.5 — ฟอนต์สมส่วนและหน้ากรอกคล้ายแบบพิมพ์
- ปรับ TH Sarabun New บนหน้าจอให้สมส่วนกับเอกสาร A4 มากขึ้น
- ลดขนาดจาก V4.4 ที่ใหญ่เกินไป แต่ยังอ่านง่าย
- ตารางหน้าจอใช้เส้นตารางชัดเจนและหัวตารางกึ่งกลางแบบเอกสารราชการ
- ช่องกรอกข้อมูลลดความโค้งและลดความสูง ให้ใกล้เคียงช่องในแบบพิมพ์
- ตารางรายเดือนมีสัดส่วนใกล้กับ ledger ตอนพิมพ์
- พื้นที่แสดงรายการใช้ลักษณะกระดาษสีขาวและเส้นกรอบเรียบ
- หน้าพิมพ์ A4 เดิมไม่ถูกเปลี่ยน เพื่อรักษาการจัดหน้า


## V4.6
- คอลัมน์ "เลขที่" และ "เลขประจำตัว" ในแบบพิมพ์อยู่กึ่งกลางชัดเจน
- ปรับสัดส่วนตารางแบบจิตอาสาให้พอดี A4 มากขึ้น
- ขยายคอลัมน์ชื่อ-สกุลและปรับคอลัมน์กิจกรรมให้สมดุล
- ปรับหน้าต่าง Preview ก่อนพิมพ์ให้ใช้สไตล์เดียวกับตอนพิมพ์จริง
- ตารางบนหน้าจอจัดแนวคอลัมน์เลขที่/เลขประจำตัวให้เหมือนเอกสารพิมพ์


## V4.7
- ปรับหัวตารางแบบบันทึกกิจกรรมจิตอาสาให้ 3 คอลัมน์แรกเป็นแนวตั้งตามตัวอย่าง
  - เลขที่
  - เลขประจำตัว
  - ชื่อ - สกุล
- ปรับความสูงส่วนหัวตารางให้สมดุลกับข้อความแนวตั้ง
- Preview ก่อนพิมพ์และตอนพิมพ์จริงใช้รูปแบบเดียวกัน


## V4.8 — หัวตารางจิตอาสาตามไฟล์ต้นฉบับ
- "เลขที่" แนวตั้งและกึ่งกลาง
- "เลขประจำตัว" แนวตั้งและกึ่งกลาง
- "ชื่อ - สกุล" แนวนอนและกึ่งกลาง
- ความสูงหัวตารางประมาณ 47.4 มม. ตามไฟล์ Word ต้นฉบับ
- สัดส่วนคอลัมน์ประมาณ 10.5 / 13.5 / 46.4 มม. และช่องกิจกรรมประมาณ 11 มม.
- Preview และ Print ใช้สัดส่วนเดียวกัน


## V4.9 — ขอบเข้าเล่มและหัวตารางแนวตั้งทุกแบบ
- หน้าพิมพ์ทุกแบบเว้นขอบซ้าย 18 มม. สำหรับเจาะ/เข้าเล่ม
- ขอบขวา 5 มม. เพื่อรักษาพื้นที่ของตารางรายเดือน 31 วัน
- หัวตาราง เลขที่ / เลขประจำตัว / ชื่อ-นามสกุล เป็นแนวตั้งและกึ่งกลางอัตโนมัติทุกแบบที่มีหัวข้อดังกล่าว
- รองรับคำหัวตารางที่ใช้คำว่า ที่ / รหัส / ชื่อ - สกุล ด้วย
- Preview และ Print ใช้ระยะขอบและรูปแบบหัวตารางเดียวกัน


## V4.10 — แสดงชื่อวันหยุดในแถบ
- วันหยุดราชการ/วันหยุดพิเศษที่อยู่ในรายการวันหยุด จะทำทั้งคอลัมน์เป็นแถบสีเทา
- แสดงชื่อวันหยุดเป็นข้อความแนวตั้งในหัวคอลัมน์ เช่น "วันหยุดพิเศษ"
- เสาร์และอาทิตย์ยังเป็นแถบสีเทา แต่ไม่แสดงชื่อยาวแบบวันหยุดพิเศษ
- ใช้ทั้งหน้าจอตารางรายเดือนและหน้าพิมพ์ A4


## V4.11 — แถบวันหยุดแบบยาวลงทั้งคอลัมน์
- ปรับวันหยุดพิเศษ/วันหยุดราชการให้เลขวันอยู่ในหัวคอลัมน์ตามปกติ
- ชื่อวันหยุดแสดงเป็นแถบข้อความแนวตั้งยาวลงมาจากใต้ช่องเลขวัน
- ลักษณะใกล้เคียงตัวอย่าง: เห็นเลขวันด้านบน และเห็นชื่อวันหยุดพาดลงมาตลอดคอลัมน์
- ใช้ทั้งหน้าจอและหน้าพิมพ์


## V4.12 — ผสานเซลล์วันหยุดพิเศษ
- วันหยุดราชการ/วันหยุดพิเศษใช้ `rowspan` ผสานเซลล์จริงตั้งแต่แถวนักเรียนคนแรกถึงคนสุดท้าย
- เลขวันที่ยังอยู่ในหัวตาราง
- ชื่อวันหยุดอยู่กึ่งกลางของเซลล์ที่ผสาน ทั้งแนวตั้งและแนวนอน
- ข้อความชื่อวันหยุดแสดงเป็นแนวตั้ง
- ใช้ทั้งหน้าจอรายเดือนและหน้าพิมพ์ A4


## V4.13 — เลขวันที่ไม่ผสานเซลล์
- เลขวันที่เป็นเซลล์หัวตารางแยกตามปกติ
- การผสานเซลล์วันหยุดเริ่มเฉพาะในส่วนรายชื่อนักเรียน (`tbody`)
- เส้นแบ่งระหว่างเลขวันที่กับเซลล์วันหยุดผสานชัดเจน
- ใช้รูปแบบเดียวกันทั้งหน้าจอและหน้าพิมพ์


## V4.14 — เลขวันที่เท่ากันทุกช่อง
- ปรับเลขวันที่ในตารางรายเดือนให้ขนาด สี น้ำหนัก และตำแหน่งเท่ากันทุกคอลัมน์
- ใช้ฟอนต์ น้ำหนัก และ line-height เดียวกันทั้งหมด
- รักษาพื้นหลังวันหยุด/วันนอกช่วงเรียนไว้ แต่ไม่ให้ส่งผลกับรูปแบบตัวเลข
- ใช้ทั้งหน้าจอและหน้าพิมพ์


## V4.15 — ปรับข้อความตำแหน่งรองผู้อำนวยการ
- เปลี่ยนบรรทัดตำแหน่งจาก
  รองผู้อำนวยการฝ่ายบริหารงานวิชาการ
  เป็น
  รองผู้อำนวยการ
  ฝ่ายบริหารงานวิชาการ
- ใช้กับหน้าพิมพ์ทุกแบบ


## V4.16 — แบบบันทึกโฮมรูมตามฟอร์มตัวอย่าง
- หัวตาราง 4 ช่อง: วัน/เดือน/ปี | รายการ/เนื้อหาสาระ | รายชื่อนักเรียนที่ขาด | หมายเหตุ
- แต่ละแถวเป็นวันจันทร์–ศุกร์
- แสดงเวลา 14.40 น. – 15.30 น.
- ช่องรายการมี ○ ท่องแม่สูตรคูณ / ○ ท่องอาขยาน / ○ อื่น ๆ
- มีเส้นประสำหรับเขียนรายละเอียดเพิ่มเติม
- คงส่วนลงชื่อท้ายหน้าเดิม


## V4.17 — โฮมรูมแสดงข้อมูลจริง + ช่องติ๊ก
- ปรับหน้ากรอกโฮมรูมให้เลือกแบบ checkbox:
  - ท่องแม่สูตรคูณ
  - ท่องอาขยาน
  - อื่น ๆ + ช่องกรอกรายละเอียด
- ข้อมูลที่กรอกจะแสดงในหน้ารายการและหน้าพิมพ์จริง
- ในแบบพิมพ์ใช้สัญลักษณ์ ☑ / ☐ ตามรายการที่เลือก
- รองรับข้อมูลเก่า: ถ้าเคยกรอกในช่องข้อความเดิม ระบบจะพยายามตีความและแสดงให้


## V4.18 — ช่อง “อื่น ๆ” อยู่บนบรรทัดเดียวกับข้อความ
- ช่อง “อื่น ๆ” และรายละเอียดที่กรอกแสดงในบรรทัดเดียวกัน
- ใช้เส้นประใต้ข้อความเป็นบรรทัดเดียวต่อเนื่อง
- ยกเลิกเส้นเขียนเพิ่มเติมที่แยกอยู่ใต้ “อื่น ๆ”
- หน้ากรอกข้อมูลก็จัดช่อง “อื่น ๆ” และช่องรายละเอียดให้อยู่แถวเดียวกัน


## V4.19 — โฮมรูมแก้ไขได้ + สัปดาห์/วันอัตโนมัติ
- ช่อง “อื่น ๆ” ในหน้าพิมพ์มีพื้นที่ 2 บรรทัด
  - บรรทัดแรกแสดงข้อความที่กรอก
  - บรรทัดที่สองเว้นเป็นเส้นประสำหรับเขียนเพิ่ม
- เพิ่มปุ่ม “แก้ไข” ในรายการโฮมรูม
- เมื่อแก้ไข ปุ่มบันทึกเปลี่ยนเป็น “บันทึกการแก้ไข” และมีปุ่มยกเลิก
- เลือกวันที่แล้วระบบเติม “วัน” อัตโนมัติ
- เลือกวันที่แล้วระบบคำนวณ “สัปดาห์ที่” อัตโนมัติจากวันเปิดภาคเรียน
- การนับสัปดาห์ใช้ช่วงวันจันทร์–อาทิตย์
- เดือนที่พิมพ์จะเปลี่ยนตามเดือนของวันที่ที่เลือกโดยอัตโนมัติ


## V4.20 — โฮมรูมข้อความ 2 บรรทัด + สัปดาห์คร่อมเดือน
- ช่อง “อื่น ๆ”:
  - ถ้าข้อความพอดี จะแสดงบรรทัดแรก
  - ถ้ายาวเกิน จะต่อข้อความในบรรทัดที่สองอัตโนมัติ
- การพิมพ์โฮมรูมจัดกลุ่มตาม “สัปดาห์จริง” ไม่แยกสัปดาห์เพราะเปลี่ยนเดือน
- ถ้าสัปดาห์คร่อมเดือน เช่น 30 กันยายน – 1 ตุลาคม จะอยู่หน้าเดียวกัน
- หัวรายงานจะแสดงเดือนแบบช่วง เช่น “กันยายน - ตุลาคม”
- ถ้าหน้าหนึ่งมีมากกว่าหนึ่งเลขสัปดาห์ ระบบรองรับการแสดงเป็นช่วง เช่น “สัปดาห์ที่ 1-2”
- วันที่ในแต่ละแถวบังคับให้อยู่บรรทัดเดียว เช่น “วันพุธที่ 30 กันยายน 2569”


## V4.21 — จัดวันที่กึ่งกลาง + พิมพ์เหมือนตัวอย่างก่อนพิมพ์
- คอลัมน์วัน/เดือน/ปี ของแบบโฮมรูมจัดข้อความให้อยู่กึ่งกลาง
- บรรทัดวันที่และบรรทัดเวลาอยู่กึ่งกลางทั้งคู่
- ล็อกขนาดตัวอักษร ความสูงแถว และเส้นบรรทัดของโฮมรูมให้ตอนพิมพ์ใช้ค่าเดียวกับหน้าตัวอย่างก่อนพิมพ์
- ทำให้หน้าพิมพ์กับหน้าแสดงผลของแบบโฮมรูมมีหน้าตาใกล้กันมากขึ้น


## V4.22 — พิมพ์ตรงกับตัวอย่างก่อนพิมพ์มากขึ้น
- จัดคอลัมน์วัน/เดือน/ปี ของโฮมรูมให้อยู่กึ่งกลางทั้งแนวนอนและแนวตั้ง

## V4.27 — สายนับเป็นมาเรียน + ตั้งเวลาโฮมรูมรายวัน
### การมาโรงเรียน
- สถานะ `ส` (สาย) นับเป็น “มาเรียน”
- ช่อง “รวมมา” รายเดือนนับทั้ง `/` และ `ส`
- สรุปรายวัน “มาเรียน (รวมสาย)” = `/` + `ส`
- ยังแสดงจำนวน “สาย” แยกต่างหากเพื่อดูรายละเอียด

### โฮมรูม
- เพิ่มปุ่ม `⚙️ ตั้งค่าเวลาโฮมรูม`
- กำหนดเวลาเริ่ม–สิ้นสุดแยกได้สำหรับ จันทร์–ศุกร์
- ค่าเริ่มต้นทุกวันคือ 14:40–15:30
- เมื่อเลือกวันที่ จะแสดงเวลาโฮมรูมของวันนั้นในหน้ากรอก
- หน้าพิมพ์โฮมรูมดึงเวลาแต่ละวันจากค่าที่ตั้งไว้โดยอัตโนมัติ

# V5.0 — Supabase Multi-user
- Login ด้วย Email / Password

- owner / editor / viewer

### ต้องตั้งค่า Google OAuth ก่อนใช้งานจริง
1. Google Cloud Console → Google Auth Platform → Clients
2. Create OAuth client → Web application
3. Authorized JavaScript origins:
   - http://localhost:8080
4. Authorized redirect URI:
   - https://kbfgkjwufhspnftxsany.supabase.co/auth/v1/callback
5. นำ Client ID และ Client Secret ไปใส่ใน:
   Supabase → Authentication → Providers → Google
6. เปิด Google provider แล้ว Save
7. Supabase → Authentication → URL Configuration → Redirect URLs
   เพิ่ม:
   - http://localhost:8080/classrooms.html
   - http://localhost:8080/reset-password.html

หมายเหตุ:
- ถ้า Google ใช้อีเมลเดียวกับบัญชี Email/Password ที่มีอยู่และยืนยันแล้ว
  Supabase จะพยายามเชื่อม Google identity เข้ากับผู้ใช้เดิมอัตโนมัติ
- ถ้าเป็นอีเมลใหม่ ระบบจะสร้าง profile เป็น teacher และยังไม่เห็นห้อง
  จนกว่า Admin จะกำหนดสิทธิ์ห้องให้
- Google OAuth สำหรับการทดสอบนี้ควรใช้พอร์ต 8080
